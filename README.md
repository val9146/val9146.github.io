# Grok Hub

Personal splash page for linking every Grok app you build or use.

**Live site (free hosting):** https://val9146.github.io

GitHub Pages serves this repo automatically because it is named `val9146.github.io`. No extra hosting account, no credit card.

## Add your own apps

1. Open `index.html`.
2. Copy one of the existing `<a class="card">...</a>` blocks inside `#apps`.
3. Change the `href`, icon, title, description, and meta line.
4. Commit. Pages updates in about a minute.

The placeholder card labeled **Your app here** is meant to be replaced.

## Local preview

Open `index.html` in a browser. No build step.

## Stack

Static HTML + CSS + a tiny canvas starfield. No framework, no npm.
